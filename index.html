HIFU Treatment Chart

시술 기록 파일을 올리면 자동으로 정리해 보여주는 도구입니다. 컴퓨터나 엑셀 수식을 몰라도 아래 3단계만 따라 하시면 됩니다.

1
파일 올리기장비에서 받은 로그 파일을 아래 칸에 끌어다 놓거나 클릭해서 선택하세요.
2
결과 확인하기버튼을 누를 필요 없이 곧바로 분석되어, 화면을 아래로 내리면 표로 정리된 결과가 나타납니다.
3
엑셀로 저장하기맨 아래 “Excel 다운로드” 버튼을 누르면 결과가 내 컴퓨터에 파일로 저장됩니다.
장비에서 다운로드한 HIFU Session Log 파일을 여기에 업로드하세요. 클릭하여 선택하거나 파일을 끌어다 놓으세요 · .txt, .csv 지원
01

Session Summary

이 세션의 기본 정보와 전체 시술 횟수(Lines)입니다. “Original”은 원본 파일의 숫자, “Calculated”는 이 프로그램이 다시 계산한 숫자로, 두 값이 같아야 정상입니다.

분석일시
02

Treatment Chart

부위마다 어떤 깊이(Depth)에 어떤 강도(Energy)로 몇 번(Lines) 시술했는지 정리한 표입니다. 맨 오른쪽 “Depth Total”은 그 깊이에서 사용한 총 횟수입니다.

03

Detailed Parameter Table

위 표를 한 줄씩 풀어서 보여주는 상세 표입니다. 요약보다 세밀하게 확인하고 싶을 때, 또는 다른 프로그램에서 데이터를 다시 활용하고 싶을 때 참고하세요.

04

Depth × Energy Matrix

부위별로 깊이(세로)와 강도(가로)를 조합했을 때 각각 몇 번 시술했는지 보여주는 표입니다. 색이 진할수록 그 조합을 더 많이 사용한 것이고, 사용하지 않은 조합은 0으로 표시됩니다.

05

Data Validation

원본 파일의 총 횟수와 이 프로그램이 다시 계산한 값이 같은지 자동으로 확인합니다. PASS면 정상이고, FAIL이면 원본 파일을 다시 확인해야 합니다. 값을 임의로 고치지 않습니다.

06

Excel 다운로드

위 결과 전체를 엑셀 파일 하나로 저장합니다. 버튼을 누르면 저장할지 묻는 창이 뜨고, “저장”을 선택하면 내 컴퓨터 다운로드 폴더에 저장됩니다.

이 페이지는 업로드한 파일을 브라우저 내에서만 분석하며 별도 서버로 전송하거나 저장하지 않습니다. 결과는 임상적 효과·안전성·권장 parameter에 대한 판단을 포함하지 않으며, 파일에 기록된 값을 그대로 구조화·집계합니다. 프로그램이 알아보지 못한 줄이 있어도 함부로 지우지 않고 화면에 따로 보여드립니다.

다시 보려면? 이 페이지 주소(링크)를 즐겨찾기에 저장해두면 언제든 다시 열어 새 파일을 분석할 수 있습니다. 다른 사람과 함께 쓰려면 이 페이지의 링크를 전달하면 됩니다. 새 파일을 올리면 이전 결과 위에 새 결과가 표시되며, 이전 결과를 다시 보려면 그 파일을 다시 올리면 됩니다.
